# 申請ポータルのGoogle Chat Botアイコン

申請ポータルなどで使用するGoogle Chat Bot用の画像を保存するリポジトリです。**公開している画像URLを変えないため、PNG画像のファイル名は変更していません。**

## 保存されている画像

| ファイル | 概要 |
| --- | --- |
| `chat-Bot-icon.png` | Google Chat Bot用画像 |
| `business-trip-bot-icon.png` | 出張関連のBot用画像 |
| `Business Trip icon.png` | 出張関連の画像 |
| `icon.png` | 汎用アイコン |

**注意：** アプリやChat Botがこれらのファイル名を使ったURLを参照している可能性があります。画像の改名・削除・移動は、参照元の確認後に行ってください。

関連：[申請ポータルの運用資料](https://github.com/noriaki-hyodo/ringi-kensho)。
